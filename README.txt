INVERSA 2.0 – versión web instalable (PWA)

IMPORTANTE
- Esta es una DEMOSTRACIÓN local: no conecta con bancos, brókeres ni mercados.
- No ejecuta compras, ventas, transferencias ni reinversiones.
- Las autorizaciones y aportaciones son simulaciones.
- No introduzcas contraseñas ni credenciales bancarias.

CÓMO ABRIRLA EN TU SAMSUNG
Para que Chrome permita "Instalar aplicación" o "Añadir a pantalla de inicio", la web debe estar publicada mediante una dirección HTTPS. Un archivo HTML abierto directamente desde "Mis archivos" puede servir para probar la interfaz, pero no permite instalar correctamente la PWA ni activar el modo sin conexión.

1. Descomprime el ZIP en un ordenador o utiliza un servicio de alojamiento web estático HTTPS.
2. Publica el contenido de esta carpeta manteniendo juntos index.html, manifest.webmanifest, sw.js y los iconos.
3. En el Samsung, abre la dirección HTTPS con Chrome.
4. Pulsa el menú ⋮ de Chrome y elige "Instalar aplicación" o "Añadir a pantalla de inicio" (el texto puede variar).
5. Después podrás abrir INVERSA desde el icono de la pantalla de inicio.

Si solo dispones del Samsung, necesitarás un servicio de alojamiento web que permita subir estos archivos desde el navegador o un ordenador prestado para publicarlos. Este ZIP es el paquete web, no una aplicación ya instalada ni una APK.

Para conectar datos reales o un intermediario autorizado harían falta desarrollo, pruebas, seguridad y cumplimiento normativo adicionales.
